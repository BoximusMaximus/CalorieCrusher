# Calorie Crusher
## Welcome!
Calorie Crusher is a website designed to answer a simple question: "How many calories have I eaten today?" If you're looking to lose weight, you've come to the perfect place. 

### Calorie Tracker
Calorie Crusher allows you to create and store food details in a database by 
manually typing the food nutrition facts yourself, or using [fatsecretPlatform](https://platform.fatsecret.com/about) to create a new food using a template. You can then create meals from any existing foods you have created, then watch it calculate
the calories in a snap. 

### Meal/Recipe Finder
Maybe you find that you ARE eating too many calories and want to find a meal that works for you. Yes, Calorie Crusher does that too. Using [TheMealDB](https://www.themealdb.com/), Calorie Crusher helps you find meals and recipes that you can 
make in your own home. While this feature is free, users are more than welcome to create an account and track the calories from any meals they found using our Meal Finder
